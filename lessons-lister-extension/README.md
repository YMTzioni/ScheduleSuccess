# Lessons Lister Extension

תוסף Chrome (Manifest V3) שסורק את אתר Success ומייצר רשימת שיעורים מסוננת לבניית לוחות זמנים.

## התקנה מקומית

1. פתח Chrome וגש ל־`chrome://extensions`
2. הפעל מצב מפתח (Developer mode)
3. לחץ `Load unpacked`
4. בחר את התיקייה: `lessons-lister-extension`

אחרי עדכון של קבצי התוסף לוחצים על כפתור הרענון (↻) שלו באותו עמוד.

## סריקה מלאה (מומלץ)

1. פתח לשונית כלשהי באתר `login.successcollege.co.il` (אם הלשונית הפעילה לא באתר, התוסף יעבור אליו).
2. לחץ על אייקון התוסף ← `סרוק את כל המסלולים`.
3. התוסף עובר על כל המסלולים באתר, על כל הקורסים בכל מסלול ועל כל השיעורים. לוקח דקה-שתיים: כל קורס נקרא פעמיים, והשרת מגביל ל-600 בקשות בדקה.
4. בסוף מוצג דוח בדיקה:
   - שורה לכל מסלול: כמה קורסים נטענו מתוך כמה שיש באתר, כמה שיעורים, כמה פריטים סוננו.
   - רשימת בעיות (קורס שלא נטען, קורס ריק, מסלול שחסרים בו קורסים). אם אין בעיות — ✓ ירוק.
   - קטע שבו לשיעורים אין סדר קבוע באתר (השרת מחזיר אותם בכל פעם בסדר אחר) מדווח כבעיה, והשיעורים בו מסודרים לפי סדר היצירה. את הסדר עצמו מתקנים בניהול האתר.
   - לכל מסלול אפשר לפתוח "מה סונן" ולראות כל פריט שהוסר ולמה.
5. `הורד JSON של כל המסלולים` שומר את הכל בקובץ אחד.

הסריקה המלאה קוראת את הנתונים הציבוריים של האתר, ולכן לא צריך להיות מחובר. מסלול שלא מופיע ברשימה הציבורית (כמו ניהול פרויקטים או UI UX) נסרק בסריקת העמוד הנוכחי.

הדוח האחרון נשמר, ונפתח שוב כשפותחים את התוסף.

### בדיקה מול הריפו

```bash
node scripts/compare-scan.mjs <all-tracks-….json>
```

מראה לכל מסלול שקיים בבונה הלוחות אם השיעורים זהים לאתר, מה נוסף או הוסר באתר, ואילו מסלולים יש באתר ועוד לא כאן.

## סריקת העמוד הנוכחי

פתח את דף המסלול (או קורס) כשאתה מחובר ← `סריקת העמוד הנוכחי בלבד` ← `סרוק עמוד נוכחי`. התוסף עובר קורס-קורס בלשונית, ובסוף `הורד JSON` שומר קובץ של המסלול הזה.

## מה נחשב שיעור

רק פריטים מסוג וידאו או שיעור. מבחנים ומשובים לא נכנסים, וגם פריטים שכותרתם מכילה:

- `מבחן` / `exam`
- `משוב על הקורס` / `טופס משוב` / `survey`
- `מצגת` / `מצגות` / `presentation` (כל פריט שקשור למצגות; קורס שכולו מצגות יורד כולו)
- ספר דיגיטלי (`ספר דיגיטלי` / `... ספר`)
- `quiz`, `test`

שיעור שמופיע פעמיים באותו קורס נכנס פעם אחת, וסיומת של קובץ וידאו (`.mp4` וכו') יורדת מהשם. קורס שנשארו בו רק מבחנים או משובים לא נכנס.
